# Консенсусний простір знань K*: Специфікація вимог до інформаційної системи персонального обліку медіа-контенту

Сесія `spetsyfikatsiia-vymoh-do-informatsiinoi-systemy`, раунд 1, сформовано 2026-09-25, конвергенція: human

## Узгоджене розуміння

<!-- SKED:NARRATIVE:BEGIN -->
Система є веб-застосунком персонального обліку медіа-контенту трьох типів: книги, серіали, фільми. Єдиний тип користувача — зареєстрований User, який має доступ виключно до власних даних. Реєстрація виконується за email, паролем і нікнеймом; паролі зберігаються хешованими; авторизаційний токен — у HTTP-only cookie із захистом від CSRF.

Основна одиниця системи — елемент контенту — зберігається в особистому каталозі та має такі атрибути: назва, тип, статус (заплановано / у процесі / завершено / відкладено), оцінку 0–10, нотатки, довільні теги з автодоповненням, обкладинку (дефолтна ілюстрація за типом або власне зображення у форматі JPEG/PNG/WebP до 5 МБ), а також тип-специфічні необов'язкові поля: для книг — автор і кількість сторінок, для серіалів — кількість сезонів, для фільмів — режисер і тривалість. При переведенні статусу в «завершено» дата завершення підставляється автоматично, якщо не введена вручну.

Для фіксації кількох переглядів одного елемента передбачено Sessions — кожна з незалежними датою, оцінкою і нотаткою. Елементи можна організовувати в іменовані Добірки через зв'язок many-to-many. Каталог і добірки підтримують сортування за датою додавання та оцінкою, а також фільтрування за типом, статусом і тегами та пошук за назвою. Особиста статистика показує кількість завершеного контенту за типами і за обраним часовим проміжком: «цей місяць», «цей рік», «весь час».

Система функціонує як веб-застосунок з адаптивним інтерфейсом; підтримуються останні дві версії Chrome, Firefox, Edge та Safari. Зовнішні медіа-бази даних не інтегруються; мова бекенду не регламентується цим документом. Усі функції соціальної взаємодії, офлайн-режим та email-підтвердження — поза MVP.

## Визначення термінів

| ID | Термін | Значення |
|---|---|---|
| K1 |  | Каталог (Catalog) — повний список усіх елементів контенту, доданих користувачем. |
| K2 |  | Елемент контенту (Content Item) — одна позиція в каталозі: книга, серіал або фільм із атрибутами (тип, статус, оцінка, теги тощо). |
| K3 |  | Добірка (Collection) — створена користувачем іменована група довільних елементів каталогу; один елемент може входити до кількох добірок одночасно. |
| K4 |  | Session — окремий запис факту перегляду або прочитання елемента; містить дату, оцінку та нотатку; для одного елемента може бути кілька Sessions. |
| K5 |  | Тег (Tag) — довільна текстова мітка, яку користувач додає до елемента для категоризації. |
| K6 |  | Статус (Status) — поточний стан роботи з елементом: заплановано / у процесі / завершено / відкладено. |
