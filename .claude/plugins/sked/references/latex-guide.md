# Writing the document with skedreport.cls

## 1. Files

```
report/
  main.tex           preamble metadata, \skedmaketitle, abstract, \skedtoc, \input lines, \skedbibliography
  sections/NN-slug.tex   one file per top-level section, in structure.md order
  figures/           external images (PDF or PNG) if any; prefer TikZ for diagrams
  refs.bib           written by `sked.py scaffold` / `sked.py bib` from source entries
  references.tex     generated by build.py (do not edit)
  skedreport.cls     copied from the plugin
```

## 2. Class interface

`\documentclass[profile=ieee|dstu|apa, lang=uk|en]{skedreport}`; add `review` to show ledger tags in the margin (build.py `--review` does this without editing the file).

Metadata: `\skedtitle[short]{Title}`, `\skedsubtitle`, `\skedauthor`, `\skedauthorlabel` (dstu), `\skedaffiliation`, `\skedorganization`, `\skeddoctype`, `\skedversion`, `\skeddate` (empty → today), `\skedcity`, `\skedyear` (dstu, default current year), `\skedudc`, `\skedkeywords`, `\skedplatform`.

Structure: `\skedmaketitle`, `abstract` environment, `\skedtoc`, `\skedunnumbered{ВСТУП}` (unnumbered heading that enters the contents), `\skedappendix`, `\skedbibliography`, `\skedgeometry{...}` (preamble only).

References: `\figref`, `\tabref`, `\algoref`, `\lstref`, `\secref`, `\eqnref`, and sentence-initial `\Figref`, `\Tabref`, `\Algoref`, `\Lstref`, `\Secref`. Labels use prefixes `sec:`, `fig:`, `tab:`, `alg:`, `lst:`, `eq:`. Do not use `\algref` (taken by algorithmicx).

Citations: `\cite{key}` works in every profile; in apa use `\citep{key}` (parenthetical) and `\citet{key}` (narrative). `\citep`/`\citet` also work in numeric profiles, so write them when the profile might change.

## 3. Ledger tags

Put `\sked{K3,K7}` at the end of every paragraph, list item, caption or table note that carries knowledge from K*, listing the entries it expresses. The tag is invisible in the final PDF and feeds the completeness score Cq. Tag deferred questions (`\sked{Q4}`) where the limitation is stated. Never tag a retracted, contested or proposed entry. Do not place tags inside section titles, footnotes or math.

## 4. Content rules

- Write only what K* contains. When the prose needs a fact that is not in K*, stop and add it to the ledger first (origin M, status proposed), get the human's agreement or a verified source, then write it.
- Numbers, dates and named results carry a citation.
- Follow the house style in `session.json` (`context.house_style`), for example no em dashes. The quality gate greps for forbidden characters.
- Keep paragraphs short; one idea per paragraph maps well to one or two ledger entries.

## 5. Figures (TikZ)

Predefined styles: `sked box`, `sked note`, `sked arrow`, `sked back` (dashed feedback arrow), `sked label` (small italic edge label with white background).

```latex
\begin{figure}[htbp]
\centering
\begin{tikzpicture}[node distance=9mm and 11mm]
  \node[sked box] (a) {Фаза 1\\Ініціалізація};
  \node[sked box, right=of a] (b) {Фаза 2\\Діалог};
  \draw[sked arrow] (a) -- node[sked label, above=2pt] {$K^{(0)}$} (b);
  \draw[sked back] ([xshift=-7mm]b.south) to[out=-90,in=-90,looseness=1.6]
        node[sked label, below=1pt] {раунди} ([xshift=7mm]b.south);
\end{tikzpicture}
\caption{Назва}\label{fig:x}
\end{figure}
```

Rules that prevent the usual defects:
- Label straight edges with `node[sked label, above=2pt]` placed on the edge path, never with free-floating coordinates.
- Route loops and feedback arrows outside the boxes (`out=-90,in=-90` below a node, or around with `|-` / `-|` paths); never `bend` an arrow across a node.
- Keep the diagram within `\textwidth`; when it grows, reduce `node distance` or wrap it in `\resizebox{\textwidth}{!}{...}` as a last resort.
- After building, look at the page image; overlapping text is the most common defect and only visible there.

In the apa profile put `\caption` before the tikzpicture.

## 6. Tables

```latex
\begin{table}[htbp]
\caption{Назва}\label{tab:x}
\centering
\begin{tabularx}{\textwidth}{@{}l l L@{}}
\toprule
Підхід & Ініціатива & Застосування \\
\midrule
... \\
\bottomrule
\end{tabularx}
\end{table}
```

Use booktabs rules only (no vertical lines). `L` is a ragged-right `X` column for text; plain `X` justifies and stretches word gaps in narrow columns. Long tables: `longtable`.

## 7. Algorithms

```latex
\begin{algorithm}[htbp]
\caption{Назва}\label{alg:x}
\begin{algorithmic}[1]
\Require ...   % prints "Вхід:" / "Input:"
\Ensure ...    % prints "Вихід:" / "Output:"
\State $K \gets ...$ \Comment{...}
\Repeat ... \Until{...}
\State \Return ...
\end{algorithmic}
\end{algorithm}
```

## 8. Code

Code that contains any character beyond Latin-1 (Cyrillic comments or strings) must use `skedcode`:

```latex
\begin{codelisting}
\begin{skedcode}
# коментар кирилицею
x = {"text": "Відстань"}
\end{skedcode}
\caption{Назва}\label{lst:x}
\end{codelisting}
```

`lstlisting` (with `language=...` highlighting) is acceptable only for pure ASCII code; under XeTeX it silently reorders non-ASCII characters. Do not mix `lstlisting` captions and `codelisting` captions in one document (separate counters).

## 9. Equations

`equation` with `\label{eq:x}`, referenced with `\eqnref{eq:x}` → (1) or (2.1) in dstu. Define every symbol in the sentence after the equation.

## 10. Build and fix loop

`python3 ${CLAUDE_PLUGIN_ROOT}/scripts/build.py --dir <session>/report --ensure-deps` on the first build, without `--ensure-deps` afterwards.

| Symptom in the summary | Fix |
|---|---|
| `Undefined control sequence` | typo in a macro, or a package the class does not load; prefer class macros |
| `Missing $ inserted` | math outside `$...$`, or an unescaped `_`, `^` in text; escape as `\_` |
| `Misplaced alignment tab character &` | escape `&` as `\&` in text and in refs.bib fields |
| undefined references | label typo, or label before `\caption` in a float (put `\label` after `\caption`) |
| overfull box in a paragraph | rephrase, allow a break in a long token (`\allowbreak`), use `\url{}` for URLs |
| overfull box in a table | switch columns to `L`/`X`, reduce content, or `\small` inside the float |
| missing glyphs | a character the fonts lack (for example emoji, rare math symbols); replace it or use math |
| hyphenation MISSING | rerun with `--ensure-deps`; if it still fails, the text stays readable thanks to `\emergencystretch` but tell the user |
| bibliography `incomplete` | fill the missing fields in the source entry's BibTeX (`sked.py apply` edit of `bib`, then `sked.py bib`) |
| bibliography `uncited` | cite it where its knowledge is used, or remove the source |
