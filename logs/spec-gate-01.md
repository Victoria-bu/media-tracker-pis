# SPEC-GATE запис — лабораторна робота №2 (SKED-діалог)

**Перевірено:** узгодженість функціональних і нефункціональних вимог, критеріїв 
прийняття та BDD-сценаріїв із результатами SKED-діалогу.

**Виявлені розбіжності:** під час генерації SRS кодинговий агент не відтворив 
раніше узгоджену вимогу автодоповнення тегів та самостійно додав нові поля 
для фільмів (режисер, тривалість) поза початковим переліком.

**Рішення:** вимогу автодоповнення тегів відновлено до узгодженого формулювання; 
додані агентом поля для фільмів прийняті як обґрунтоване розширення після 
ручного перегляду. Специфікація затверджена як базова версія v1.0 для 
подальшого SDD-циклу.
