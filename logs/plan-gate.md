# PLAN-GATE — лабораторна робота №3

**Перевірено:**
- Декомпозиція покриває всі 30 REQ-F і 9 REQ-NF — так, кожен рядок матриці простежуваності має номер Issue (1-4)
- Залежності логічно узгоджені — лінійний ланцюг Issue 1→2→3→4→RELEASE-GATE
- Gate розташовано перед критичним переходом — RELEASE-GATE блокує перехід до релізу v1
- План не містить функціональності поза SRS — кожен Issue посилається лише на наявні REQ ID
- Суттєві ризики мають заходи контролю — реєстр ризиків (R-01…R-10) містить конкретні заходи пом'якшення
