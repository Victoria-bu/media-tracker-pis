### 3. Нова поведінка оформлена (крок 14)

У `docs/api-addendum.md` задокументовано 6 поведінок, відсутніх або
неповністю описаних у SRS:

| # | Поведінка | Тип |
|---|---|---|
| 1 | `on_hold` / `in_progress` як snake_case | уточнення REQ-F-006 |
| 2 | HTTP 409 при повторній реєстрації з тим самим email | уточнення REQ-F-001 |
| 3 | HTTP 409 при повторному додаванні елемента до добірки | адендум REQ-F-015 |
| 4 | Сортування Sessions на сервері (новіші — першими) | уточнення REQ-F-013 |
| 5 | Статистика фільтрується за `Item.completedAt` | уточнення REQ-F-022 |
| 6 | Ресурси іншого користувача → 404, а не 403 | адендум REQ-NF-002 |

Результат: **✓ Нова поведінка задокументована**

### 4. Відхилення від SRS

Жодна вимога SRS не порушена. Усі пункти адендума є адитивними або
роз'яснювальними, ніяка функціональна вимога не видалена й не змінена по суті.

Результат: **✓ Відхилень немає**
