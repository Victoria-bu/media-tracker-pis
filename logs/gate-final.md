## 3. Основні людські рішення

| Рішення | Обґрунтування |
|---------|--------------|
| Реєстрація/авторизація входить до MVP | Потрібно для синхронізації між пристроями |

| Клієнтський прототип реалізовано після REST API | `client/` — демонструє UI без зміни серверної специфікації |

## 5. Задокументовані обмеження (не блокують GO)

- Клієнтські вимоги (фільтри, пошук, сортування в UI) не тестуються у REST API — відповідно до `docs/api-design.md §1`.
- `VALIDATION_ERROR` без деталізації полів (DEV-01) — `docs/known-deviations.md`.
- Prism v5 не перевіряє cookie-автентифікацію — захист підтверджено інтеграційними тестами.
- «Поточний місяць/рік» визначається за UTC-годинником сервера.
