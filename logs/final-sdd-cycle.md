## 3. Основні людські рішення

| Рішення | Контекст |
|---------|---------|
| Реєстрація/акаунт входить до MVP | Потрібно для синхронізації між пристроями |
| Соціальні функції (друзі, рекомендації) відкладено | Не входить до MVP v1 |
| Зовнішні бази даних (TMDB, Google Books) відкладено | Введення контенту вручну у MVP |
| Повторні перегляди — окремі Sessions | Потрібно для коректної статистики за період |
| Обкладинка: дефолтні ілюстрації + можливість завантажити власне зображення | Замінено початковий варіант «емодзі» |
| Пошук за назвою та сортування — додано до SRS | Ініціатива власника під час перегляду |
| Поля автора та кількості сторінок для книг — додано | Ініціатива власника |
| `basis=sessions` вибрано замість `basis=completedAt` (ADD-07-A) | Дозволяє рахувати повторні перегляди окремо |
| V-01 (формат `createdAt`) виправлено через TDD | Red-коміт `2c0df19`, Green-коміт `3e4a580` |
| DEV-01 (уніфікований `VALIDATION_ERROR`) — свідомо не виправляється у v1 | Описано в `docs/known-deviations.md` |
