# Концепція інформаційної системи

## Тема
Інформаційна система персонального обліку медіа-контенту

## Опис
Інформаційна система призначена для персонального обліку медіа-контенту
(книги, серіали, фільми), який переглядає або читає користувач.
Користувач додає контент до особистого каталогу із зазначенням типу
(книга/серіал/фільм), статусу (заплановано/у процесі/завершено/відкладено),
оцінки (від 0 до 10) та коротких нотаток; контент автоматично впорядковується
за типом (окремі категорії для книг, серіалів і фільмів). Кожна позиція                                                  
може бути позначена тегами (наприклад, для жанрів «fantasy», «comedy»,                                                      
«drama»), які задає сам користувач; на основі цих тегів буде доступне                                                         
додаткове фільтрування та пошук у власному каталозі. Користувач може   
створювати власні добірки (наприклад, за роком перегляду, за оцінкою,
"улюблене") та об'єднувати в них довільні позиції зі свого каталогу.
Система формує особисту статистику (кількість прочитаного/переглянутого
за період). Додаткова функціональність — можливість ділитися власними
добірками або надсилати рекомендації друзям.
